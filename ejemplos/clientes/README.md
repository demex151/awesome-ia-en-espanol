# Clientes de ejemplo (ficticios)

> ⚠️ **Todos estos perfiles son ficticios.** Nombres, negocios y ciudades son inventados para ilustrar cómo usar la lista. Cualquier parecido con personas reales es coincidencia.

Cada archivo describe a una persona típica, su problema y una **ruta de 4 semanas** usando solo recursos de la lista principal.

| Perfil | Archivo | Punto de partida |
|---|---|---|
| Pintor / contratista | [pintor-contratista.md](pintor-contratista.md) | Nunca usó IA |
| Dueña de restaurante | [restaurante.md](restaurante.md) | Usa el celular para todo |
| Maestra de secundaria | [maestra.md](maestra.md) | Quiere preparar clases y entender la IA |
| Freelancer de diseño y código | [freelancer.md](freelancer.md) | Técnico, quiere automatizar |

## Cómo usarlo
1. Elige el perfil más parecido a ti.
2. Sigue la ruta semana por semana; cada paso enlaza a un recurso de la lista.
3. ¿Tu caso es distinto? Copia un archivo, cambia los datos y propón tu propia ruta con un pull request.
